# B.IA.DI — APKs

Este repositório guarda só os APKs da **B.IA.DI**, a assistente de voz para BYD/Denza.
O app nos carros consulta o release [`biadi`](../../releases/tag/biadi) e se atualiza sozinho.

- Primeira instalação: baixe o `.apk` do release `biadi` e instale (aTV Tools, pendrive ou ADB).
- Depois disso, as atualizações chegam sozinhas.

O código-fonte fica em um repositório privado.
